# Conceptual Design and CAD Modeling of a Formula E Powertrain System

This report examines the powertrain system in Formula E cars, 
focusing on its key components battery, inverter, electric motor, 
transmission and their integration for optimal performance. The study 
highlights design considerations, such as acceleration performance, torque
speed characteristics, and single-speed transmission optimization. 
Mathematical models are used to analyze power requirements, top speed, 
and acceleration for conceptual design and components sizing. 
Additionally, it discusses how Solidworks as the CAD software is 
employed to validate component geometries and simple mechanical 
integration.
